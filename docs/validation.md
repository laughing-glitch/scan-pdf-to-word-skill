## 发布版工具

自动化检查覆盖：

- PDF 拆页与原页码对应，输入字节不变，中文/空格路径。
- 原生段落、表格、合并单元格、空白填写栏和批注。
- 内容遗漏检测、批注锚点检查、编辑保存回读。
- 拒绝覆盖输入以外的已存在输出；拒绝错误合并范围。
- 技能包结构、内部引用、安装目录复制及防覆盖行为。
- Windows / macOS / Linux 上运行上述 Python 回归；安装器按对应系统检查。

GitHub Actions 的运行状态是实际跨系统检查证据。它不启动 WorkBuddy / Codex / Claude Code 的图形界面，不测量不同宿主模型的视觉识字准确率，也不代表三种客户端的完整人工验收。

发布前还在本机运行了通用脚本的拆页、Vision / Tesseract 草稿、Word 构建及渲染验收。详细执行结果在发布说明中记录。

## 维护原则

对脚本改动运行相关回归；对生成布局改动重新渲染查看。转换质量问题应使用一份可分享的最小样本重现，不把某个教材的特例硬编码成所有文件的规则。
